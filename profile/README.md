# Mono Labs

Mono Labs is the enterprise home for Monolythium engineering and related R&D.
The canonical Monolythium source now lives in the
[monolythium](https://github.com/monolythium) organization.

For new work, use the current Monolythium repositories. Legacy v1 and
Cosmos/EVM-era repositories are frozen for reference and should not be used as
the source of current chain, wallet, SDK, explorer, or network configuration.

## Organization Map

| Organization | Purpose |
|--------------|---------|
| [monolythium](https://github.com/monolythium) | Canonical source for the current protocol, SDK, docs, website, wallets, explorer, operator tooling, whitepaper, and designs. |
| [mono-labs-archive](https://github.com/mono-labs-archive) | Frozen legacy v1 repositories, including old chain configs, wallets, Monarch CLI, LythiumBFT, and old Monoscan. |
| [monolythium-vision](https://github.com/monolythium-vision) | Temporary staging area for projects that have not yet graduated into the canonical organization. |
| [mono-labs-org](https://github.com/mono-labs-org) | Mono Labs corporate and historical shared repositories. |
